# 测试用例与验收说明

文档基准：2026-10-29。测试对象为本地虚拟银行 Agent 源码，所有账户、认证、行情、付款和审核均为合成样例。

测试使用 Python 标准库 `unittest`，不需要 pytest、银行接口或模型 API。当前源码共定义 **162 个测试方法**；同一方法内的 `subTest` 和多次断言不另计为独立用例。Windows 上应执行 162 项；Linux 上其中 2 项 Windows CMD 专属检查按条件跳过。2026-11-01 加固版新增 `tests/test_hardening.py`（14 项），覆盖认证不可自证、一次性安全码、股票确认门、金额量化与非法金额、共享限额账本、脱敏、内网地址拒绝、审计签名、会话淘汰与确认 nonce。测试通过表示列出的回归路径符合断言，不代表已经完成生产安全认证或全路径证明。

## 运行方式

在源码根目录（能看到 `README.md`、`banking_agent/`、`tests/` 的位置）运行：

```powershell
python -X utf8 -m unittest discover -s tests -v
```

只运行首次收款人专项或网页专项：

```powershell
python -X utf8 -m unittest discover -s tests -p test_recipients.py -v
python -X utf8 -m unittest discover -s tests -p test_web.py -v
```

Windows 如使用已安装的 Python Launcher，可把命令开头改为 `py -3`。源码要求 Python 3.11+。测试会使用临时目录、模拟工具、临时监听在 `127.0.0.1` 的 HTTP 服务，并在测试结束后清理；不会连接真实银行或证券服务。若本机环境禁止回环端口或子进程，需要在允许这些操作的开发环境运行。

执行结果应以实际终端的 `OK`、`FAILED`、`ERROR` 和 `skipped` 为准。最新人工交付前应重新运行，不沿用旧截图中的测试数量或结果。
