# 评委阅读指引

本包是「星河虚拟银行 Agent」的最终提交物，包含可直接运行的 Windows 免安装程序、
全部源码与测试、以及三份提交文档。

## 三分钟看懂这个项目

1. 双击根目录的 **启动网页演示.cmd**（Windows 10/11 x64，无需安装 Python、无需联网）。
2. 浏览器会自动打开本机页面，输入：**给张三转账2888元**
   → 弹出首次收款人身份核对（此刻未扣款）→ 核对虚构尾号后付款。
3. 再输入：**给张三转账3000元** → 这一次必须核对摘要并确认，体会「小额直转 / 大额确认」的分界线。
4. 想看安全机制，输入：**切换到IM** → 再转账 → 会被拦在「等待增强认证」，
   页面顶部出现一次性演示安全码；输入 **认证 123456**（换成页面显示的码）后任务自动恢复。

## 一句话定位

这不是一个「会聊天的银行」，而是一条**能被检查的资金链路**：
认证不能靠嘴说、资金不能绕确认、限额不能靠开新窗口重置、审计改一行会被发现。

全部账户、交易、行情与身份均为虚构样例，不连接真实银行、证券或身份服务。
